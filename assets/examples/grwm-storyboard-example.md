# Example: GRWM storyboard production reference sheet

This example demonstrates a hybrid storyboard infographic plus production reference sheet.

## Structural summary

- 16:9 wide cinematic storyboard sheet.
- Top character/style reference strip.
- Main 6-panel storyboard grid with timecodes.
- Each panel contains action, dialogue, bullet notes, props/symbols.
- Bottom technical reference bar.
- Strong consistency requirements for the protagonist.

## Reusable takeaways

- Reference strip helps unify character, style, camera texture, lighting, and props.
- The main grid should carry the story beat sequence.
- Technical bar turns a visual prompt into a production reference sheet.
- Use short labels and notes rather than dense paragraphs inside the image.

## Abstracted template

```text
Create a 16:9 cinematic storyboard infographic and production reference sheet for [duration] [concept]. Use [style language]. Layout: clean production storyboard board, numbered panels, short titles, concise notes, optional reference strip, optional technical bar.

TOP REFERENCE STRIP: [character/style/scene/camera/lighting/props references]

MAIN STORYBOARD GRID: [N] numbered panels.
PANEL 1 — [title] ([time/beat])
[frame description]
Notes: [camera/action/emotion/props]

BOTTOM TECHNICAL BAR: [camera/lens/motion/color/audio/editing/constraints]

OVERALL AESTHETIC: [unified visual language and consistency constraints]
```
