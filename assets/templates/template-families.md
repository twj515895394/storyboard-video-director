# Template Families

These are built-in starting families. They work even when no custom case cards exist.

## 1. Cinematic Narrative Storyboard

Use for short films, dramatic scenes, emotional transformation, and character-driven moments.

Default: 4–8 panels or shots; medium shot density; strong emotion continuity; cinematic lighting.

## 2. Action / Mechanical Sequence

Use for chase, sabotage, combat, robot, vehicle, tool-use, or physical cause-effect videos.

Default: high shot density; strong action causality; macro inserts for trigger details; crisp SFX.

## 3. Product Demonstration / Functional Proof

Use for showing how a product works or why it matters.

Default: problem → operation → effect → proof → payoff. Strong functional causality.

## 4. Commercial / Brand Pitch Board

Use for ads, brand films, product launches, and pitch decks.

Default: reference strip + hero frames + technical bar; concise brand memory point; polished but not generic.

## 5. Vlog / GRWM / Social Short

Use for influencer, daily routine, travel, social platform storytelling.

Default: handheld intimacy; event beats; natural camera imperfections; optional dialogue; social pacing.

## 6. Documentary / Realist Observation

Use for realistic social scenes, workplace observation, field documentary, training examples.

Default: restrained camera; authentic environment; natural light; minimal visual exaggeration.

## 7. Training / Explainer Storyboard

Use for educational content, PPT visuals, conceptual explanation.

Default: cognitive path: problem introduction → analogy → mechanism → example → summary.

## 8. Mood Film / Music Video / Abstract Visual

Use for atmosphere, emotion, poetic images, MV, conceptual visuals.

Default: weak causality; visual motifs and rhythm drive transitions; audio/BGM may be central.

## 9. Hybrid Production Reference Sheet

Use when the user wants both storyboard and production reference board in one image.

Default: top reference strip + main storyboard grid + technical reference bar.
