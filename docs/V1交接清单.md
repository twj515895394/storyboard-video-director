## V1 默认规则

- 主要面向 AI 视频制作和影视前期。
- 支持故事版图片 Prompt 和视频 Prompt。
- 图片故事版默认 16:9，中文标注，动态分镜数量，最多 16 格。
- 视频 Prompt 不绑定固定 Seedance 格式，而是使用自适应维度系统。
- 声音设计自适应，不强行加入对白、旁白或 BGM。
- 视频字幕 / 屏幕文字 V1 默认关闭，除非用户明确要求。
- 案例库是增强项，不是依赖项。
- 复杂视频支持 Multi-Clip Controller。

## 后续建议

1. 继续收集优秀视频 Prompt 和故事版 Prompt。
2. 使用“案例入库”分支生成案例卡。
3. 每积累 5–10 个同类型案例，就整理一次模板家族。
4. 后续可以补充模型适配参考：Seedance、Kling、Veo、Runway、Sora。
5. 后续可以增加更强的 JSON 校验依赖，例如 `jsonschema`，但 V1 先保持纯标准库。
