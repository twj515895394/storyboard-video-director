# storyboard-video-director 使用手册

## 这个 Skill 是什么

`storyboard-video-director` 是一个面向 AI 视频制作的影视前期 Skill。

它不是单纯的提示词模板，而是一个从主题到分镜、故事版图片 Prompt、视频 Prompt、案例入库和模板沉淀的工作流。

## 典型用法

### 1. 从简短主题生成完整方案

```text
我想做一个 15 秒 AI 短片：一个小机器人在废弃工厂里发现自己被替换了。帮我做完整 AI 视频前期方案。
```

输出通常包括：

- 创意摘要
- 故事方向
- Sequence / Beat 拆解
- Shot Map
- gpt-image2 故事版图片 Prompt
- 视频生成 Prompt
- 可执行性检查

### 2. 只生成故事版图片 Prompt

```text
帮我把这个主题做成一张 16:9 影视故事版图片 Prompt，用于 gpt-image2。
```

默认：

- 16:9 宽幅
- 中文分镜标注
- 动态分镜数量，最多 16 格
- 可包含顶部 Reference Strip 和底部 Technical Bar

### 3. 只生成视频 Prompt

```text
帮我生成 Seedance 风格的视频提示词，15 秒，动作节奏快一点，不需要对白。
```

默认会考虑：

- 时长和镜头密度
- 角色/主体一致性
- 场景路线
- 动作因果链
- 动作连续性
- 音效 / BGM / 对白是否需要
- 可执行性检查

### 4. 案例入库

```text
把这个优秀视频 Prompt 案例入库，帮我拆解它的结构，并沉淀成可复用模板。
```

输出：

- 案例拆解卡
- 可复用模块
- 不适合复用的部分
- 模板家族建议
- 变体方向

## 重要默认规则

### 案例库不是必需

即使没有录入任何案例，这个 Skill 也会使用内置 SOP 正常生成高质量结果。

案例库只是增强项，用于让结果越来越贴近你的风格和偏好。

### 视频字幕默认关闭

Seedance 等视频模型对字幕/屏幕文字稳定性不一定好，因此 V1 默认不主动生成字幕、屏幕贴纸或复杂文字层。

除非你明确要求，否则视频 Prompt 不会主动加入字幕。

### 声音设计自适应

声音设计是检查维度，但不是每个视频都强行生成对白、旁白或 BGM。

例如：

- 机械动作类：重点写 SFX
- 情绪片：可以写 BGM 和环境声
- Vlog：可写口播或自然对白
- 无声氛围片：可以明确 minimal sound / ambient only

## 推荐工作习惯

1. 先给一个简短主题。
2. 让 Skill 给 3–5 个创意方向包。
3. 选择一个方向或混合多个方向。
4. 让 Skill 生成 Shot Map。
5. 再根据需要输出故事版图片 Prompt、视频 Prompt 或完整包。
6. 遇到好案例时，及时触发案例入库。
